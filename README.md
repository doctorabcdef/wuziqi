# 棋间 · 共享五子棋

游戏地址：**https://doctorabcdef.github.io/wuziqi/**

15×15 自由五子棋，所有设备打开首页都进入同一个公共棋盘。棋步、双方颜色、当前局数保存在云端；刷新页面或换设备后自动恢复。页面在前台约每 250 毫秒检查云端棋局，请求不重叠；隐藏页面暂停检查，回到页面时立即刷新。连接失败时逐步延长重试间隔，避免重复请求。实际跨设备同步仍包含网络及服务器响应时间。连续落子和连续悔棋都会立即显示，操作按顺序在后台保存，不必等待上一手网络响应。半透明棋子表示仍在同步；冲突或失败时撤回尚未确认的操作，并读取云端局面。

## 使用

- 点击交叉点落子，双方轮流执棋，五连或长连获胜，无禁手。
- 每方有六个预设颜色，也可以点击颜色选择器自定义任意颜色。
- 棋子以双方选定的颜色显示，不带数字标记；橙点标出最后一步。
- 点击悔棋直接撤回一步；重新开局仍需确认，并保留双方颜色。
- 公共聊天自动加载云端历史消息，可查看更早记录；重新开局不会清空聊天。昵称可修改，所有访客都能看到消息。
- 点击“太慢了”“搞快点好不”或表情即可快捷发送，也可输入文字后发送。回车发送，Shift + 回车换行。消息点击后立即显示，后台按顺序保存，可继续发送下一条；未确认的消息会标示状态，失败后可重试。
- 每台设备打开网页后，先点击页面顶部的“开启本设备声音”。之后任一设备发送“太慢了太慢了”或“搞快点好不”，其他页面会自动播放对应录音；连续语音依次播放，不会因为上一条未播完而丢弃。同一浏览器的其他标签页也可接收。
- 语音仍可从聊天历史点按重播；首次加载和翻阅旧记录不会自动播放。未获浏览器播放许可的消息会保留在播放队列，点击开启声音后继续播放。开启声音后，后台标签页约每秒检查聊天；手机锁屏或浏览器冻结页面时无法保证实时发声，保持网页前台可获得最佳效果。
- 这是所有访客共用的一局，任何访客均可落子、修改颜色、悔棋或重开。
- 断线时保留棋盘画面并暂停操作；恢复连接后重新读取云端，不会重复提交未知结果的落子。

## 部署结构

- GitHub Pages 托管静态网页。推送到 `main` 后，`.github/workflows/pages.yml` 仅发布前端静态文件。
- `backend/` 是持久化 API 的完整源代码，使用 Cloudflare Worker + D1，通过 Sites 部署。项目标识见 `backend/.openai/hosting.json`。
- `config.js` 指向已部署 API 地址。没有 GitHub 令牌或数据库私钥进入浏览器。
- GitHub Pages 仅负责网页，云端 API 必须保持运行，跨设备保存才能工作。更新后端需单独发布对应 Sites 项目，推送 GitHub 本身不会更新后端。
- 数据表迁移位于 `backend/drizzle/`；修订号的原子条件更新防止同时操作覆盖棋盘。部署不清空已保存数据。
- 聊天记录独立保存在 D1 的 `chat_messages` 表中，唯一请求编号防止重试造成重复消息；分页按消息编号读取。聊天独立轮询，不占用棋盘操作队列。浏览器只保存昵称与设备标识，不作为聊天记录的存储来源。
- 语音文件位于 `assets/voice/`，由 GitHub Pages 提供；`voice-clips.js` 将两个固定消息标识映射到录音，消息标识沿用聊天数据库保存，旧客户端仍可看到语音标题。前台聊天同步约每 250 毫秒检查一次，慢请求不重叠，断线逐步延长重试间隔。

## 本地开发与验证

使用 Node.js 24 或更新版本：

```sh
npm ci
npm test
npm run dev
```

打开 http://127.0.0.1:4173 。本地预览使用 `artifacts/local-game.sqlite`，与线上公共棋盘隔离；本地 `config.js` 响应自动指向本地 API。

```sh
npm run test:browser
npm run test:interaction
npm run test:sync
npm run test:chat
npm run test:voice
npm run test:broadcast
```

浏览器测试使用本机 Microsoft Edge；需先启动本地服务。它通过两个独立浏览器会话验证落子和颜色同步、刷新恢复、断网恢复、悔棋及手机布局。后端测试覆盖真实 SQLite 持久化、并发冲突、请求幂等、非法输入和四个方向胜负。

交互测试另外模拟延迟响应，验证立即落子、免确认悔棋、重复点击保护，以及冲突或断网后的界面回退；测试不修改线上棋局。

聊天测试使用独立 SQLite 和两个浏览器会话，覆盖云端记录恢复、更早历史、快捷消息和表情、输入法回车、失败重试去重、草稿保留、消息安全显示及手机布局，不写入线上聊天。

语音测试验证慢网络下立即显示消息、连续发送、录音播放与历史恢复，以及发送失败的重试。

广播测试使用三个网页（含同一浏览器的两个标签页），验证实际音频依次完整播放、播放授权后的队列恢复、暂停继续、历史消息静音及手机布局；测试消息只写入独立 SQLite。
